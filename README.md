# Calculadora por Linha 01

Primeiro projeto do desafio de **um pequeno projeto por dia**.

Calculadora simples em Python que roda no terminal.

## Funcionalidades
- Soma, subtração, multiplicação e divisão
- Tratamento de divisão por zero
- Tratamento de entradas inválidas
- Opção de calcular novamente

## Como rodar
1. Instale o Python 3
2. Execute: `python calculadora.py`

## Exemplo
Digite o primeiro número: 10
Digite o segundo número: 2
Digite a operação (soma, subtracao, multiplicacao, divisao): divisao
Resultado: 5.0
